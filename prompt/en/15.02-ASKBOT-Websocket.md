## Stage 02 - Create Chatbot Page Using SSE, Implement Chatbot Functionality Using Written Actor Model

### Guidelines
- ui/askbot: Please create the chatbot page we're building here, it should work without authentication.
- Conversation between user (USER) and chatbot (ASKBOT) should be possible using SSE.
  - The core functionality of the chatbot is in src/Memorizer/Actors/ChatBotActor.cs. Please use this.
  - SSE has unidirectional characteristics~ requests are in API form and only responses are received via SSE. The actor model's response results should be transmitted in stream form using SSE.
- ChatBotActor has a session concept and is maintained. When first used, create with GUID and permanently store in browser cache for use.
  - Pressing the New Session button allows proceeding with a new session. At this time, ChatBotActor is also newly created and SSE reconnects.
- UI Details
  - There is an input field at the bottom for requesting to ASKBOT, submittable with Enter key. Since a submit button is needed on mobile, please create a button in icon form.
  - At the top, user requests and chatbot responses are displayed in conversation format.
  - The top content can be long and should be scrollable, with requests fixed at the bottom.
  - Display the chatbot's response process step by step referring to the implemented actor model. For example, display something like "Searching for content related to 'search attempted keywords' in memory..."
  - When the final answer is generated, display it in markdown format. Markdown format can include code view, links, images, tables, and mermaid diagrams.
    - Refer to src/Memorizer/Views/Home/View.cshtml for markdown presentation style.
  - All progress and responses are output naturally in keyboard input animation format using Stream. The input field is disabled while receiving responses. The input field is reactivated when the response is finally completed or fails.
- If slight improvements are needed for Chatbot actor model to naturally transmit in stream form while connecting SSE stream, improvements can proceed.
