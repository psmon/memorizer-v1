This project uses .NET 9.0 and is composed of a full-stack (API, UI) architecture.
Please review the additional information below and perform the improvement instructions.

## Improvement Instructions
- We want to improve the menu. Currently, the menu works in desktop mode, but it collapses and disappears in mobile mode.
- Please improve so that the menu is always visible even in mobile mode.
  - When the screen is small (mobile), add a toggle function so that clicking the hamburger menu icon shows the menu, and clicking again hides it.
  - Even when the screen is large (desktop), add a toggle function so that clicking the hamburger menu icon shows the menu, and clicking again hides it.
- When the menu is closed, show a hamburger icon, and when open, show an X icon with natural animation. Please search the web for this animation effect and apply it.

## Local Testing Method
- Can be tested locally using docker-compose.local-psmon.yml. Use this file if there are Docker operation issues.
- The default configuration may already be running. Do not bring everything down with the down command, only rebuild and restart memorizer-app.
- This application is built and operated through memorizer-app. When rebuild/restart is needed, use only Docker without dotnet CLI.
- Once completed, please run the application. Direct UI testing is planned, and improvements can be made based on feedback.
