This project uses .NET 9.0 and is composed of a full-stack (API, UI) architecture.
It supports search and vector search using PostgreSQL, and also enables vector search utilizing Neo4j.

The ASKBot feature has been implemented to create a conversational chatbot that searches memories interactively.
