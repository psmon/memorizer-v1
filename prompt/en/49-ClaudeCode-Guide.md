It supports search and vector search with PostgreSQL, graph exploration with Neo4j,
and also includes an LLM-based ASK conversational bot. It additionally provides various AI features through an MCP interface.

## Core Features for Skill Creation
- Start with a conversation: "What role do you want to create?"
- Provide role selection buttons first:
  - `"Developer"`, `"Planner"`, `"DevOps"`, `"QA"`, `"Custom Input"`, etc.
- After role selection, suggest recommended sub-skill titles.
  - Buttons should be generated by LLM + include direct input.
- Based on role + selected sub-skill title, continue additional Q&A to gather supporting details needed for writing the skill.
  - LLM should ask appropriate follow-up questions.
  - Repeat to achieve the goal of collecting correct additional information.
  - This module is the most important; use an Agent-Actor approach.
- When enough information is collected, proceed to skill generation and show progress state.
- After skill generation is complete, no need to print all details in chat.
  - Provide result as buttons/links instead.
- Clicking a result button should open in a new window.
- Generate a prompt dedicated to achieving this skill-creation flow.
  - Skills should follow Claude Code skill file structure.
  - `SKILL.md` should be viewable in markdown format and support copy functionality.
  - Skill should also support sharing; clicking share should provide short-link access.
  - Reuse/align with existing share features.
- Design both:
  - the LLM prompts
  - and in-app operational prompts
  to meet the above goals.
