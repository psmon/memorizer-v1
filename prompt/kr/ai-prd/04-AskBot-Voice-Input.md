PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며

프로젝트 위치및 설명,로컬 테스트방법 을 참고해 지침을 수행해주세요

# 지침 - AskBot 음성 입력 기능

## 기능 개요
AskBot에서 음성으로 질문을 입력할 수 있는 기능을 추가합니다.
브라우저의 Web Speech API를 활용하여 음성을 텍스트로 변환합니다.

## 구현 요구사항
- 대화 입력창 옆에 마이크 버튼을 추가합니다.
  - 버튼 클릭시 음성 인식 시작
  - 다시 클릭시 음성 인식 중지
  - 음성 인식 중에는 버튼 색상 변경 및 애니메이션 표시
- Web Speech API (SpeechRecognition) 사용
  - 한국어(ko-KR) 및 영어(en-US) 지원
  - 환경설정으로 기본 언어 선택 가능
  - 음성 인식 결과를 입력창에 자동 입력
- 음성 인식 상태 표시
  - "듣고 있습니다..." 안내 텍스트 표시
  - 인식된 텍스트 실시간 미리보기
- 음성 인식이 지원되지 않는 브라우저에서는 마이크 버튼 숨김 처리
- 멀티모달 기능(이미지 업로드)과 병행 사용 가능

## 프로젝트 위치및 설명
- src/Memorizer/ 하위디렉토리에 있습니다.
- src/Memorizer/Controllers - API컨트롤러가 있습니다.
- src/Memorizer/Views - UI관련 뷰파일이 있습니다.
  - ui/askbot 페이지 수정 필요
- src/Memorizer/Actors - 액터모델이 있습니다.
  - ChatBotActor.cs - 대화 처리 액터
- src/Memorizer.IntegrationTests - 통합테스트 프로젝트가 있습니다.

## 로컬 테스트방법
- 빌드오류만 해결합니다.
- 빌드오류 잡고나서 테스트는 직접예정으로 피드백에따라 수정합니다.
- 음성 인식 테스트는 HTTPS 환경 또는 localhost에서만 가능합니다.
