이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.

프로젝트 위치및 설명,로컬 테스트방법 을 참고해 지침을 수행해주세요

# 지침 - 그래프 시각화 개선

## 기능 개요
ui/graph 페이지의 그래프 시각화 기능을 개선하여 더 직관적이고 인터랙티브한 탐색 경험을 제공합니다.

## 구현 요구사항
- 그래프 시각화 라이브러리 활용 (vis.js, cytoscape.js 등 기존 사용 라이브러리 확인)
- 노드 개선
  - 노드 크기: 연결된 관계 수에 따라 크기 조절
  - 노드 색상: 메모리 타입별 색상 구분
  - 노드 라벨: 제목 + 생성일 표시
  - 노드 호버: 미리보기 툴팁 표시
- 엣지(관계) 개선
  - 관계 유형별 선 스타일 구분 (실선, 점선 등)
  - 관계 레이블 표시 토글
  - 엣지 두께: 관계 가중치에 따라 조절
- 인터랙션 개선
  - 줌 인/아웃 컨트롤 추가
  - 노드 드래그하여 위치 조정
  - 노드 클릭시 연결된 노드 하이라이트
  - 노드 더블클릭시 해당 메모리 상세 페이지로 이동
- 필터링 기능
  - 메모리 타입별 필터
  - 관계 유형별 필터
  - 날짜 범위 필터
- 레이아웃 옵션
  - Force-directed (기본)
  - 계층형
  - 원형
