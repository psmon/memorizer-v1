프로젝트 위치및 설명,로컬 테스트방법 을 참고해 지침을 수행해주세요

# 지침 - AskBot 프롬프트 템플릿 기능

## 기능 개요
AskBot에서 자주 사용하는 질문 패턴을 템플릿으로 저장하고 재사용할 수 있는 기능을 구현합니다.
"[주제]에 대해 요약해줘", "[코드]를 리뷰해줘" 같은 템플릿을 미리 정의하여 빠르게 질문할 수 있습니다.

## 구현 요구사항
- 프롬프트 템플릿 관리
  - 템플릿 구조: 이름, 설명, 템플릿 텍스트, 변수 목록
  - 변수는 {{variable}} 형식으로 정의
  - 예시: "{{topic}}에 대해 한국어로 쉽게 설명해주세요"
- 기본 제공 템플릿
  - 요약 요청: "다음 내용을 요약해주세요: {{content}}"
  - 코드 리뷰: "다음 코드를 리뷰해주세요:\n```\n{{code}}\n```"
  - 번역 요청: "다음을 {{target_language}}로 번역해주세요: {{text}}"
  - 비교 분석: "{{item1}}와 {{item2}}의 차이점을 설명해주세요"
- UI 개선
  - 입력창 위에 템플릿 선택 드롭다운 추가
  - 템플릿 선택시 변수 입력 폼 표시
  - 변수 입력 후 전송시 완성된 프롬프트로 질문
  - 사용자 정의 템플릿 추가/수정/삭제 (인증 필요)
- 템플릿 저장소
  - 로컬 스토리지에 사용자 템플릿 저장
  - 서버에 공유 템플릿 저장 (인증된 사용자)
- API 엔드포인트
  - GET /api/templates - 템플릿 목록 조회
  - POST /api/templates - 템플릿 생성
  - PUT /api/templates/{id} - 템플릿 수정
  - DELETE /api/templates/{id} - 템플릿 삭제
