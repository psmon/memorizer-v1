# 사전정보
- prompt/kr 하위는 한국어로 작성된 markdown 문서들이 있습니다.
  - prefix로 넘버링 된 문서들은 순서대로 진행되었던 실제작동 지침문서들입니다. 
- prompt/en 하위는 영어로 작성된 markdown 문서들이 있습니다.
  - prefix로 넘버링 된 문서들은 순서대로 진행되었던 실제작동 지침문서들입니다. 
  

# 지침
- 한국어로 작성된 문서를 영문으로 번역해주세요, 한국어파일은 유지하면 됩니다.
- 이미 작성된 버전도 있기때문에 추가된 파일을 번역해주세요
- translate.md 파일은 이 파일의 지침으로번역될 필요없습니다.
- readme.MD 파일은 기존파일에서 업데이트된 부분을 번역 추가해주세요
  - Version 1.0.8 - [ContentView-Upgrade](13-ContentView-Upgrade.MD) 에 해당하니 버전설명시 참고하며 마이너 버전이 증가합니다. 누락되거나 중복되지 않도록 주의하며 누락시 업데이트합니다.
  - 15.01-,15.02- 와같이 하위에 숫자가 붙은경우, 분할해 개선된 케이스로 readme 설명시 동일버전으로 설명합니다. 
  - 파일이름이 변경될수도 있으며 readme.MD에 연결된 상대경로 연결문서가 깨진게 없나 마지막으로 확인합니다.
- prompt/kr/agent.md
  - 프로젝트를 구성하는 파일입니다. 번역은 필요없으며 최신 정보로 유지해주세요
  - 프로젝트 구조를 추가로 반영해 업데이트해주세요 (새로운 주요 핵심 코드파일이나 디렉토리 추가,삭제 등)
  - 마지막 버전 반영은 가장최근지침의 앞자리 숫자값을 이용합니다.
    - ex> prompt/kr/35-Ai-Driven-Idea.md 가 최신지침이라면 35로 반영
