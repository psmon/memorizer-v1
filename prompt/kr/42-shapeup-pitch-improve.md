    - 이 목적 달성을 위한 프롬프팅을 구현합니다. 요청프롬프트를 시각화 보드를 그리기위한 목적을 달성합니다. ( 보드템플릿은 활용하지않습니다. )
    - 통합생성에 이용된 백엔드및 기능은 유지해주세요(추후 다시살릴예정)
  - 기존 기능은 다음과같은 순서로 표시되게 콤보박스 개선
    - Problem -> BreadBoard-> Fat Maker -> Risk -> Pitch : ShapeUP 생성방법론 순서와 일치
    - Board 템플릿이 최근 개선되었기때문에.. 이 템플릿을 채워 넣을수 있도록 기존 ShapeUP 생성프롬프트 개선
