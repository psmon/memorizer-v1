이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.
프로젝트 위치및 설명,로컬 테스트방법 을 참고해 개선지침을 수행해주세요

# 개선하는 기능

- news/ai-tech-now - 메모리조각을 뉴스화하는 페이지입니다.
  - Most Popular
    - 10개가 현재표시됩니다. more 5 버튼을 눌러 다음 항목 5개가 생기게 해주세요(지속작동가능) 
- news/ai-tech-now/article - 뉴스 본문페이지입니다.
  - 본문으로 제목이 두개 연속 표시됩니다. 한번만 나오게해주세요 (두번째 등장 제목 중복제거)
  - 이 페이지 링크 공유하기를 누르면 공유링크가 복사됩니다. - 도메인주소는 설정되어있으니 참고해 상대경로랑 조합
  - 코드유형이 mermaid인경우 렌더링해주세요 - ui/view 를 참고
  - 본문이 모바일에서 우측 빈공간이 생기는것같습니다. 꽉차게 style 개선

- ui : 홈에 해당하는 경로입니다. 메뉴를 가지고 있으며 제일하단 메뉴에치 
   AITECH-NEWS 메뉴를 추가하고 "news/ai-tech-now" 메뉴클릭시 새창 랜딩되게

- 빌드를 수행해 빌드오류를 수정합니다.
- 추가된 코드는 유닛테스트를 작성해 수행합니다.

- 개발 db인 postgres는 로컬 docker를 통해 이미 구동되어 있어서 db조회및 파악가능합니다. - 런타임오류 발생및 기능오류 제보기 read로 이용가능
- 정상적으로 구동되면 직접 테스트 예정으로 피드백대기합니다.
  - 공식배포는 닷넷도커를 통해 리눅스기반 배포되지만... 로컬테스트는 윈도우로 수행해 피드백예정입니다.
