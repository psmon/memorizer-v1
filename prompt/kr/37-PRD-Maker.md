이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.

프로젝트 위치및 설명,로컬 테스트방법 을 참고해 지침을 수행해주세요

- PRD Maker 상세한 기능은 PRD Maker 지침에 추가설명 

## PRD Maker 지침
스토리 단위의 PRD를 입력하면 , 이벤트 스토밍으로 해석하는 웹페이지를 만들고 싶습니다.
페이지는 textarea와 버튼으로 구성되어 있습니다. 

사용자가 textarea에 PRD 내용을 입력하고  버튼을 클릭하면 이벤트 스토밍 결과를 보여줍니다.

이벤트 스토밍 결과가 나오면 예제맵핑 기능이 다음으로 수행됩니다.
이벤트 스토밍의 결과 기반으로 가상의 협업자들이 토론을 통해 예제맵핑을 만들어냅니다.
토론과정을 완성합니다.

토론이 완성되면 다음으로 예제맵핑 만들기가 시도됩니다.
예제맵핑을 완성해가면 되겠습니다.

- 이벤트 스토밍은 DDD의 원칙에따라 생성합니다.
- 이벤트 스토밍 결과는 다음과 같은 형식으로 출력됩니다:
    - 이벤트(Event)
    - 명령(Command)
    - 액터(Actor)
    - 정책/조건/제약 사항
    - 애그리거트/바운디드 컨텍스트
- 예제맵핑은
    - 사용자 스토리 (Story)	논의할 기능 또는 요구사항의 간단한 설명
    - 예제 (Example)	사용자 스토리와 관련된 구체적 사례 또는 시나리오
    - 규칙 (Rule)	예제를 통해 드러나는 도메인의 비즈니스 규칙
    - 의문점 (Question)	논의 중 생기는 모호한 부분이나 추가 확인이 필요한 사항
- 이벤트는 비즈니스 도메인의 흐름순서에 따라 표현해줍니다.
- 모두완성되면 결과 공유하기 버튼이 생기며 결과를 숏링크 공유할수있도록합니다.
- PRD Shared Page 에서는 공유된 모든 결과를 볼수있도록하며 카드스타일의 페이지뷰로 구현합니다.
### 부가지침
- LLM-EX에 새롭게 설정된 LLM을 이용합니다.
- 목적달성을 위해 프롬프트 설계를 합니다.
- 응답은 한국어로 답할것을 명확히 지시하고 스트리밍 방식을 확인해 자연스럽게 표시합니다.
  - LLM을 스트리밍을 이용할시 실시간 반영을 위해 SSE방식을 이용합니다. 
- markdown 스타일로 결과를 생성하도록하며 mermaid 다이어그램및 코드블락도 지원합니다.
  - /ui/view/{id} 페이지뷰를 참고해 스타일을 표현하는 뷰어를 구현합니다.(관련 모듈 활용)
 

### 추가개선
- 이벤트 스토밍에서 머메이드가 코드스타일로 표현되는데 다이어그램으로 표시해죠
- 진행이 자동으로 한꺼번에 되는데 사용자가 버튼을 눌러 단계별로 진행할수있도록 개선
  - 추가기능 :예제 맵핑결과후 다음 기능으로, 예제맵핑을 참고해 완성된 제안 요구사항을 다시 생성합니다. 
- PRD Maker에 다음과같은 기능소개 
  - 스토리 요구사항이 빈약함을 인정하고 시작하는 기능으로 요구사항이 충분하지 않은 상태에서 출발해도 괜찮다는 점을 안내
  - 마지막 단계에 요구사항을 보완함으로 새로운 PRD를 통해 재시도 가능함을 안내
  - PRD Maker의 하단 페이지에는 머메이드로 간단한 다이어그램으로 프로세스를 안내합니다.
- 쉐어할시 4단계 예제 맵핑 결과까지 저장되는거 확인됨
  - 5단계 보완된 PRD 결과도 저장되도록 개선
  - 쉐어버튼은 4단계또는 5단계 완료후 활성화되도록 개선 진행된것만큼 공유하면됨
- 쉐어 뷰페이지 개선
  - 모바일에서 반응형으로 작동해 표가 너무 좁아져 글가독이 떨어짐
    - 테이블 스타일을 개선해 가독성을 높입니다.
    - 테이블이 넓어지는 경우 가로스크롤이 가능하도록 개선
    - 글을 읽기편하도록 테이블 폭 최소 너비를 지정
      - 최소15글자가 한라이엔 들어가도록
- 공유할시 타이틀이 "PRD 분석" 으로 고정이며 이를 개선하려함
  - 내용을 참고해  공유하는 타이밍에 제목 생성해(LLM활용)
    - 30자이내로 타이틀을 만들것
