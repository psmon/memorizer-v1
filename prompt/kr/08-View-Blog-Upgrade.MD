

이 프로젝트는 MCP-Memorizer로  LLM Agent가 필요한 지식을 제공하는 프로젝트입니다.
/ui 엔드포인트는 메모리를 조회하는 페이지입니다. 이것을 참고해 /ui/blog 페이지를 추가해 블로그 같은 형태로 메모리를 조회할수 있는 페이지를 추가하고자 합니다.
다음 지침과 참고정보를 활용해 페이지 생성을 진행해주세요 


# 지침
- 메뉴명은 Blog Memories로 합니다. 페이지의 타이틀도 Blog Memories 로 합니다.
- 이 페이지는 로그인없이 작동가능합니다.
- 블로그 Style로 메모리를 조회하며 페이징 API기능을 이용하지만, 스크롤에 따라 자동으로 다음 페이지를 불러오는 기능을 제공합니다.
- 본문은 300자정도 프리뷰로 보여주고~ View More 버튼을 눌러 전체 내용을 볼수 있도록 하며 페이지이동없이 팝업뷰로 전체내용을 볼수 있도록 합니다.
- 메모리는 최신순으로 보여줍니다.
- 메모리의 제목과 본문에 대한 키워드 검색기능이 상단에 있습니다. sql like %검색어% 형태로 검색이 가능합니다. 검색후에는 동일한 페이지에서 필터링된 결과만 보여줍니다.
- 키워드 검색창 하위에는 type및 tags 간편 버튼형 필터기능이 있습니다. 필터는 복수 선택이 가능하며 선택된 필터는 키워드 검색과 함께 적용됩니다. 
- 적용된 필터는 x 버튼을 눌러 해제할수 있습니다. type 필터를 상단에 tags필터를 하위에 구분해주세요
- 필터버튼에는 현재 검색기준에 해당하는 메모리수가 표시됩니다. 예를들어 "type: article (123)" , "tags: tech (45)" 등으로 표시됩니다.
- 코드를 최종완성후 빌드가 되는지 확인후 , 빌드오류수정 유닛테스트는 없어도됩니다.

# 참조정보
- "src/Memorizer/ 에 프로젝트 파일일 있습니다.
- "src/Memorizer.IntegrationTests/" 에 유닛테스트 파일이 있습니다.
- "src/Memorizer/Services/Memory.cs" 에 메모리 저장소를 조회및 관리하는 서비스 코드가 있습니다.
- postgres 스키마는 "src/Memorizer/migrations" 에 있습니다.
