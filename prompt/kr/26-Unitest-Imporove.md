# 유닛테스트 개선
- 지금 작동시키면 대부분 실패합니다.(시간오래걸림) 유닛테스트 대상이 되는 코드를 분석해 유닛테스트 코드부터 수정합니다.
- 유닛테스트 코드가 다 작성되면 빌드가 수행되는지 먼저 확인합니다.
- 빌드가 성공하면 유닛테스트를 실행하여 통과하는지 확인합니다.
- 유닛테스트가 통과하지 않으면 실패하는 유닛테스트면 유닛테스트를 수정합니다.
  - 원본 코드는 수정하지 않습니다.(중요)
