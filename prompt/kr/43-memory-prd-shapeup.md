이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.

프로젝트 위치및 설명,로컬 테스트방법 을 참고해 개선지침을 수행해주세요

# 개선지침
- PRD Maker와 ShapeUP에서 메모리 조각을 참고해 작성기능을 개선하려고합니다.
- 먼저 기존작동기능이 다음프롬프트에 완성되었으니 참고하세요
  -  prompt/kr/39-PRD-Maker-02.md : PRD메이크에서 메모리 조각 참고해 PRD 작성기능이있습니다.
  -  prompt/kr/42-shapeup-pitch-improve.md : 메모리조각 참고를 아직하고 있지않습니다.
- 메모리 참조기능 업그레이드
  - PRDMaker PART
    - 3단계 예제 맵핑 토론단계 에서 메모리를 검색합니다. 메모리 조각 활용패턴  참고해 로직개선
  - ShapeUP PART
    - Free Board 생성단계에서 메모리 조각을 참고해 작성기능을 추가합니다.
      - 요청프롬프트에서 연관된 메모리 조각을 검색해 참고하도록 개선 메모리 조각 활용패턴을 참고
  - 메모리 조각 활용패턴  : 코드가 분리되어도 됩니다.
    - 검색과정과 검색된문서가 적합한지 판단하는 추론과정 두가지를 분리
    - PRDMaker에서는 토론과정에 메모리가 참여하며 검색로직을개선
      - 2단계 이벤트 스토밍에서 유용한 키워드 3가지를 추출 또는 생성해 검색시도
      - 연관성은 0.3이상으로 각각 높은것 하나씩 이용
      - 추론단계에서는 검색된 각각의 문서가 이벤트 스토밍과 적합한지 판단되면 참고 메모리로 활용
      - 최대 3가지이기때문에 참석자는 메모리1,메모리2,메모리3과 같이 구분해 토론에 참석
    - ShapeUP에서는 Free Board 작성시 메모리가참여하며 검색로직개선
      - 작성요청 프롬프트에서 주요 키워드 3가지를 추출또는 생성해 검색시도
      - 연관성은 0.3이상으로 각각 높은것 하나씩 이용
      - 추론단계에서는 검색된 각각의 문서가 Free Board 작성에 적합한지 판단되면 참고 메모리로 활용
      - 프리보드는 Text영역을 추가로 작성할수 있으며, 참고했을시 참고한 메모리 조각의 정보와 연관성을 추가로 표시합니다.  
    - 버튼을 눌렀을때 진행과정을 스텝별로 보여주고, 채택과정을 토스트팝업으로 정보성으로 표시합니다.
      - ex> "메모리조각 2개를 검색했습니다. 그중 2개가 적합하다고 판단되어 참고했습니다." 
    - 이 목적이 달성하기 위해 프롬프트를 잘 설계합니다.
