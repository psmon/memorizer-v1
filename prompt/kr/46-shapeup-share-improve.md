이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.
프로젝트 위치및 설명,로컬 테스트방법 을 참고해 개선지침을 수행해주세요

# 개선지침
- /ui/shapeup/shares 는 공유된 페이지들을 볼수 있으며 공유리스트와 공유뷰페이지를 개선하려고합니다.
  - 뷰페이지를 보면 공유된 페이지를 볼수 있지만 이미지형태로 나타납니다.
    - 해당 내용을 사용하려고 텍스트 복사가 불가능합니다.
    - 에디팅 기능이 있으며 에디팅(/ui/shapeup)에 사용한것을 활용해 뷰어가능하도록
      - 뷰어페이지에서 편집버튼 클릭시 /ui/shapeup 페이지로 이동 (편집버튼은 상단Create New버튼 오른쪽)
      - 이동시 마지막 편집된기준 으로 프론트사이드에서 불러오기
      - 이동시 생성에 이용된 프롬프트는 옮길필요없음 
      - 보드캔버스에 있는 요소들은 모두 불러와지며 
      - 기존 DB저장구조가 있음으로 데이터구조확인해 최대환 마이그레이션없이 호환 - 어쩔수없는경우만 마이그레이션 진행
    - 기존 요소 변경및 수정이 가능하지만 저장반영은 할필요 없습니다.
    - PNG,SVG 내보내기가 있으며 이때는 최종편집된 기준으로 내보내기
    - 공유된 페이지를 불러올때 프롬프트도 같이 불러와지도록
      - 이용된 프롬프트는 하단에 펼치기 형태로 UI로 제공, 보드캔버스에 포함시키지 않기
      - 프롬프트 펼치기 UI는 기본적으로 접혀있으며 펼치기 아이콘을 클릭하면 열림
      - 프롬프트 펼치기 UI는 복사버튼이 있어 복사가능
      - 프롬프트 펼치기 UI는 프롬프트가 없는경우 표시하지 않음
- ui/shapeup 편집시 SVG ICONS를 한번이용하고 나면 펼치기 자동 닫히는데 불편함 자동으로 안닫히게 개선(기본값은 닫힘 유지)
- ui/shapeup 편집툴 다음과같이 개선
  - 편집툴 순서는 다음순으로
    - DRAWING TOOLS 
    - PROPERTIES
    - SVG ICONS
    - BOARD TEMPLATES (접기,펼치기 추가 - 기본값 접기이며 자동안닫히게)
  - 요소 복사붙이기 지원, 컨트롤+C,컨트롤+V 하면 복사생성 안겹치게 복제대상 우측에 붙이기
    - 그룹핑 기능이 있으며.. 그룹핑역시 동일하게 그룹을 유지한채로 복사지원 
  - 편집툴(DrawingTOOLS영역)이 길이가 길어 편집하기 불편함
    - 편집툴의 높이를 우측 캔버스 작업영역과 동일하게 높이를 맞추고 자연스럽게 스크롤가능하도록
      - 해당영역 마우스오버시 해당툴만 스크롤 , 전체스크롤영향안가게 
    - (fix)편집툴의 높이는..우측의 보드판(캔버스)영역의 높이와 일치를 이야기한것임..현재 툴의 높이가 더 높게 그려짐
