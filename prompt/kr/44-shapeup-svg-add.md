이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 그래프 탐색도 가능하며
추가로 LLM을 활용한 ASK 대화형봇 기능도 구현되어 있으며, MCP 인터페이스로도 다양한 AI기능을 제공합니다.

프로젝트 위치및 설명,로컬 테스트방법 을 참고해 개선지침을 수행해주세요

# 개선지침
- ShapeUP에서는 프리 캔버스 그리기 기능을 지원하며 추가요소
  - SVG BOX를 추가하는 기능
    - 벡터이미지를 그릴때 추가
      - 백그라운드는 투명이되게
      - 테두리선은 색상및 두께조절가능 - 기존속성컨트롤 확인
      - 크기조절가능 ,이동가능 ,삭제가능, 회전가능등 기존 제공되는 조작기능 적용(기존코드확인)
      - 다른도형과 그룹핑가능
  - 별도로 SVG BOX를 이용하는 유용한 생성된 아이콘을 생성해 드로잉시 이용할수 있도록
    - 예: 화살표 아이콘, 사용자 아이콘, 클라우드 아이콘, 서버아이콘, 데이터베이스 아이콘 등
    -  DRAWING TOOLS 영역에 공간절약을 위해 펼치지기 모드를 이용해 추가 
- SVG BOX 프론트 기능이 추가되면 다음을 후속개선 진행
  - 테스트 피드백을 줄것이기때문에 통과된후 후속개선진행(사전작업x)
  - ShapeUP에는 AI생성기능이 있으며 SGV를 그릴수 있도록 프롬프트를 설계해 SVG BOX를 필요하면 활용할수 있게
  - 공유(Shared) 기능도 있으며 SVG BOX가 포함된경우도 공유및 DB에 저장가능하도록
    - DB저장및 조회기능 점검

  - UX개선 : SVG BOX 그리면, 프리요소 드로잉 입력하게 프로퍼티제공
    - 완성되기전에는 샘플컨텐츠를 입력창에 기본값으로 넣어서 생성 , ex> SVG모양 그리는 디폴트 svg로 기본값생성
