이 프로젝트는 dotnet 9.0을 사용하며 풀스택(API,UI) 으로 구성되어 있습니다.
PostgreSQL를 이용한 검색및 벡터검색이 가능하고 Neo4j를 활용 벡터검색도 가능합니다.
ASKBot 기능을 탑재해 대화 반응형으로 메모리를 검색하는 챗봇을 만들고자하며 다음 요구사항을 참고 새로운 기능을 추가해주세요


## 아이디어 지침

### 흐름
- 챗봇을 실행하는 버튼은 둥근 플로팅형태로 우측하단에 있으며 버튼명은 ASK BOT입니다. 버튼 아이콘을 부각할수 있도록 약간의 애니메이션 효과를 줍니다.
- 플로팅 버튼을 클릭하면 챗봇대화창이 나타납니다. 처음 클릭시 챗봇은 "안녕하세요 저는 IT테크 지식을 가진 메모리봇입니다. " 라고 인사합니다.
- 브라우저의 언어설정을 확인해 고정된 문구를 번역해 표현합니다. 한국 or 나머지로 나머지는 영어로처리 두개의 언어만 지원합니다.
- 사용자의 응답은 제출이 아닌 엔터키로 제출가능해야하며, 모바일에서는 채팅입력버튼이 있을수 있습니다. 아이콘 모양으로 버튼을 만들어주세요
- 챗봇대화창은 닫기버튼이 있으며 닫으면 플로팅 버튼만 남습니다.
- 챗봇대화창은 이전 대화내용을 스크롤로 확인
- 챗봇대화창은 모바일에서도 잘보이도록 반응형으로 만들어주세요
- 챗봇대화창은 대화내용이 길어질수 있으므로 스크롤이 가능해야 합니다.
- 챗봇대화창은 닫았다가 다시 열면 이전 대화내용이 유지됩니다.
- 챗봇의 기능은 챗봇 Agent에 있습니다. 이 기능수행을 위한 프롬프트도 작성해주세요 , 프롬프트는 Agent전용 프롬프트로 Prompts 디렉토리하위에 템플릿형태로 관리합니다. -영문 프롬프트로만 작성
- 영어/한글을 자동 감지하기때문에 프롬프트에서는 해당언어로 답변할것 이란 프롬프트를 마지막에 포함합니다.

### 챗봇 Agent
- 챗봇의 세션은 사용자별로 구분할수 있으며 브라우저캐시를 이용해 유지합니다.
- 챗봇은 세션별로 액터모델 하나가 대응합니다. 대화가 3일동안 없다고하면 서버자원을 위해 액터는 스스로 종료합니다.
    - 액터모델이 가진 타이머를 이용합니다. 처음 대화가 시작될때 액터가 생성되며, 동일 세션이있을시  동일액터를 사용합니다.
- 챗봇과 관련한 주요 로직은 액터모델을 통해 상태기반의 이벤트 드리븐 방식을 이용합니다.
- 사용자가 질문을 던질때는 API를 이용하고 챗봇을 통해 응답을 받을땐 SSE(Server Sent Event)방식을 이용합니다.
- LLM을 이용할때 스트림방식을 주로 이용합니다.
- 사용자가 IT관련 테크질문이라고 하면 챗봇은 메모리에서 검색해 답변합니다.
- 사용자가 IT관련 테크질문이 아닌경우 챗봇은 메모리가아닌 일반 LLM응답을 합니다.
- 검색을 시도하는경우, 여기서 제공되는 벡터검색을 시도하며 유사도 0.3이상인것중 연관성이 높은 컨텐츠 5개를 검토합니다. 검색이 진행되는 과정의 UI를 챗봇내에서 보여줍니다.
    - 예를들면 "메모리에서 '검색시도되는 키워드'  관련내용을 검색중입니다."
    - 사용자의 요청과 응답의 결과가 맞는지 검증도 하며, 맞지않은경우 다른키워드 조합으로 검색을 시도하며 최대 3번까지만 시도합니다.
- 메모리에서 요구내용이 없을시 일반 LLM 응답을 이용합니다.

- docker-compose.local-psmon.yml 를 통해 로컬에서 테스트 가능합니다. 도커구동 문제시 이파일을 사용할것..
