
이 프로젝트는 MCP-Memorizer로  LLM Agent가 필요한 지식을 제공하는 프로젝트입니다.

posggres DB에 저장된 메모리를 Neo4j 그래프 데이터베이스로 동기화하고, LLM을 활용해 관계를 생성하는 기능을 추가하는 프로젝트입니다.
인증기능이 없어 간소화된 인증기능을 만드려고 합니다.

다음 지침을 준수해 프로젝트 업데이트를 진행합니다.

# 지침
- 로그인은 페이지는, 홈경로에 존재하며  DB사용없이 환경설정을 통해 매칭검사합니다. 상단은 이프로젝트를 설명하는 프리뷰를 넣습니다.
- 로그인이 안되었는데, 로그인이 필요한 페이지에 접근시 로그인가능 페이지로 전환합니다.
- 인증은 로그인된(관리자)와 로그인안된 두가지 종류만 있습니다.
- MCP SSE인터페이스도 인증기능이 없으며~ 간소화된 API-KEY를 통해 수행될수 있게 개선합니다. 설정은 환경설정을 통해 가능합니다.


비로그인 접근가능메뉴는 다음과 같습니다. 
- All Memories : https://mcp.webnori.com/ui
- Graph View : https://mcp.webnori.com/ui/graph
- DetailView : https://mcp.webnori.com/ui/view/f24539b8-af02-4ac3-86be-74239ac0fbd0
  - 이 페이지에 Edit/Delete 기능이 포함되어 있으며 이 기능은 노출되지 않고, API로도 허용되면 안됩니다.

로그인시에는 모든 메뉴를 포함 기존과 동일하게 수행됩니다.


# 코드완성후 테스트 지침
- 코드작성이 모두 완료되면 유닛테스트를 수행하면서, 오류및 잘못작동되는 부분을 개선해갑니다. 자연어를 cypher 쿼리로 변환하는 부분은 LLM이 활용됨으로 올바른 cypher 쿼리가 생성되는지 확인을하면서 프롬프트도 개선해갑니다.
- 유닛테스트가 완료되면 local port 5012로 구동해... 여기선 개선된 내용으로만 api test를 수행합니다. postgres,ollama,neo4j 등은 이미 구동되어 있으며 docker ps 를 통해 구동여부및 포트를 확인할수 있습니다.
